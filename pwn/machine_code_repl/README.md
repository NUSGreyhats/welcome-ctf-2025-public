# Details

I was looking at https://p403n1x87.github.io/getting-started-with-x86-64-assembly-on-linux.html and trying to learn x86\_64 assembly language, so I wrote an interactive x64 assembly code prompt to run assembly!

I thought it was impressive, so I'm hosting this REPL as a service for you to learn assembly with me too!

What could possibly go wrong?

Advice: You don't really need to read the source code of the emulator to solve this. Try learning about assembly and system calls!
